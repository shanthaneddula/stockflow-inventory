## Catalog Notes

### Schema Version 2.0 Structure
Each item follows the common envelope structure:
- **id**: Stable unique identifier
- **itemName**: Human-readable display name
- **category**: Product category (vape, nicotine pouch, roll-your-own, hookah accessories, glass, diagnostic, culinary)
- **brand**: Manufacturer or brand name
- **family**: Product family/series (optional)
- **edition**: Specific edition/SKU (optional)
- **active**: Boolean for catalog status
- **sort_order**: Display ordering

### Category-Specific Attributes
Each category owns its attribute structure:
- **Vape**: flavor, puff_count, nicotine, product_type, device_form_factor
- **Nicotine Pouch**: flavor, strength_value, strength_unit, pouch_format, can_quantity
- **Roll-Your-Own**: variety_style, cut_type, net_weight, weight_unit, package_form, tobacco_classification
- **Glass**: product_type, dimensions_size, material, connection_style, color
- **Hookah/Accessory**: item_type, size_quantity, material, compliance_metadata
- **Culinary**: item_type, size_quantity, cylinder_material, compliance_metadata

### Ordering Policy Data
Per-item ordering policy:
- **stockUnit**: Counted unit (piece, can, pouch, bag, cartridge)
- **orderUnit**: Supplier ordering unit (piece, box, carton, sleeve, case)
- **unitsPerOrderUnit**: Conversion quantity
- **minimumOrderUnits**: Minimum order quantity
- **orderMultiple**: Case multiple requirements (optional)
- **reorderMode**: Calculation method (required minus current, minimum-stock, target-stock)
- **manualOverride**: Specific item override (optional)

### Unverified Entries
Entries marked with ⚠️ are draft/unverified and require:
- Concrete sellable item confirmation
- Stable ID assignment
- Ordering unit verification
- Regulatory compliance metadata
- Vendor SKU structure confirmation

Do not automatically convert prose descriptions into inventory SKUs for unverified entries.
